# A股做T候选分析器

一个面向 **A股底仓做T研究** 的本地工具。核心目标不是预测“明天一定涨跌”，而是回答三个更实际的问题：

1. **哪些股票历史上更适合做T？**
2. **为什么适合，主要空间和风险来自哪里？**
3. **点进单股后，历史正T/倒T的机会和成本表现怎样？**

> 当前 `dev/v0.2-market-scanner` 是产品化开发分支。`T Score v0.1` 仍是研究评分，不构成投资建议，也没有被宣传为已经验证的超额收益模型。

## 当前用户流程

启动 Streamlit 后，主界面只保留三条主线：

### 1. 做T候选榜

支持两种范围：

- **自选池**：输入股票代码，直接生成候选榜。
- **全市场候选**：先做日线粗筛，再对候选计算 T Score；不会对5000多只股票无差别下载分钟数据。

候选榜直接展示：

- 排名
- 股票代码 / 名称
- T Score / 等级
- 适合度
- 风险标签
- 平均振幅
- 历史日内空间
- 中位成交额
- “为什么适合/为什么不适合”
- 实际命中的数据源

如果当前股票池没有实时成交额，全市场模式不会机械取代码前 N 只冒充筛选结果：有历史评分缓存时使用历史 T Score 做粗筛；两者都没有时会明确提示先建立有效候选池。

### 2. 单股分析

- 日线 T Score 与评分拆解
- 历史收盘走势
- 5分钟历史T机会
- 分钟分析统一使用 **不复权（raw/none）名义价格**

### 3. 正T / 倒T回测

- 正T：先买额外仓位，再卖原有可卖底仓
- 倒T：先卖原有底仓，再低位买回
- 明确建模 T+1 底仓约束
- 佣金、最低佣金、卖出印花税、额外费率、滑点均可配置
- 同时展示：
  - 因果滚动Z分数基线
  - 历史最佳单次T空间（后视机会天花板，明确不是策略）

## 数据口径

工具明确区分两套价格口径：

- **日线评分 / 长期特征：前复权 qfq**
- **5分钟T机会 / 交易成本 / 正T倒T回测：不复权 raw/none**

原因：手续费、最低佣金、股数约束依赖真实历史名义价格，不能用前复权价格替代。

DuckDB 缓存的身份键已经包含：

```text
code + interval + adjust + datetime
```

因此 raw / qfq / hfq 不会混表。前复权数据还会通过重叠窗口检测复权尺度变化，必要时重建该股票的旧缓存区间。

## 当前 T Score v0.1

总分 0–100，当前研究权重：

- 25% 振幅能力
- 20% 流动性
- 20% 日内可交易空间
- 15% 均值回归
- 10% 趋势稳定
- 10% 风险控制

振幅不是越大越好，过低没有做T空间，过高则增加单边和极端波动风险。

候选榜上额外增加了一个**解释层**，把已有评分转换成“适合度 / 风险 / 原因”，但解释层不会修改 T Score 数值。

## 数据源架构

价格和证券身份分开处理，避免某一个公开接口失效导致整个工具瘫痪。

当前价格链包含：

- Eastmoney
- AKShare
- Tencent 历史K备用
- 可选 Tushare
- BaoStock 在联网验收和沪深历史场景中作为独立来源

证券身份 / 点时股票池还支持：

- BaoStock 历史证券快照
- 上交所 / 深交所 / 北交所身份适配
- 北交所官方当前证券列表

## 历史研究与正式OOS

项目保留了较完整的研究层，但它已经从主界面降为次级能力：

- Walk-forward + gap 防未来泄漏
- 多股票横截面 Rank IC
- 分位组 / Top-Bottom
- 随机零假设
- 市场状态分层
- 点时股票池
- 权重晋级门槛

构建研究数据集：

```bash
python -m app.dataset_cli \
  --provider auto \
  --start 2025-01-01 \
  --end 2026-08-07 \
  --with-baostock \
  --exact-snapshots \
  --minute-limit 100 \
  --minute-selection stable-hash
```

正式数据集默认用稳定哈希抽取有界分钟样本，不读取期末 T Score，避免用未来评分反向选择历史股票。未来机会标签只接受评分序列中紧邻的后续交易日；分钟数据缺日时标签保持缺失，不会跳到数月后的可用记录。

正式 OOS 校准入口默认 **fail-closed**，只接受数据集输出的 `oos_eligible_panel`。未知血缘、估算成交额、未验证的北交所迁码拼接、带未来评分选择偏差的 `latest-score` 分钟样本都不会被用于正式晋级。

## 风险说明

本项目用于历史行情研究和策略验证，不构成投资建议。实际交易仍受 T+1、停牌、涨跌停、佣金、最低佣金、印花税、滑点以及不同板块交易规则影响。

公开行情接口可能限流、改字段或停止服务，因此数据层始终保持可替换和可降级。

# 多股票横截面 T Score OOS 校准

单只股票时间序列验证只能回答“这只股票自己的历史分数是否领先自己的未来机会”。最终全市场做T筛选更关键的问题是：**同一个交易日的候选股票里，高 T Score 的股票是否真的拥有更大的未来净T机会**。

## 评价口径

横截面校准按“日期 × 股票”构建面板，采用因子研究中常见的逐日横截面口径：

- Spearman Rank IC
- Rank IC 正值比例、标准差与 ICIR
- 按日分位组未来净T机会
- Top-Bottom 分位差
- 优化权重 vs 固定 v0.1 / 振幅 / 流动性 / 日内空间
- 随机零假设百分位与经验 p 值

## 时间隔离

外层训练/测试按日期严格 expanding walk-forward，并保留 `gap=horizon`。每个外层训练窗口内部独立选择候选权重，未来测试日期只用于最终 OOS 评价。

候选权重满足：

- 六项权重非负
- 总和为 1
- 单项权重默认不超过 55%
- 候选集合由固定 seed 生成，可复现

## 性能

候选搜索不会为每个候选重复执行 pandas `groupby/rank`。实现会预计算每个日期的特征矩阵和标签排名，再使用 NumPy 做矩阵乘法和排名相关计算。

当前合成横截面测试由约 22 秒下降至约 1.8 秒，同时保留结果语义。

## 晋级门槛

优化权重不能因为某一折表现好就替换 v0.1。横截面专属 gate 默认同时要求：

1. 优化后平均日横截面 IC 比最强简单基准至少高 0.03；
2. 外层未来折中正 IC 比例至少 60%；
3. 随机零假设经验 p 值中位数不高于 0.20；
4. 优化分数的 Top-Bottom 未来净T机会差为正。

任何一项未通过都返回 `promote=False`。

## Demo 结果的正确解读

离线 Demo 只验证统计和防泄漏逻辑，不代表真实股票市场。当前 Demo 横截面结果并不稳定，优化权重没有通过晋级门槛；这是预期允许出现的结果，工具不会强制输出“优化成功”。

## 幸存者偏差：真实校准的硬门槛

真实历史横截面研究不能只拿“今天仍上市的股票”回看过去，否则会产生幸存者偏差。正式全市场校准需要 point-in-time 股票池，至少正确处理：

- 历史上市日期
- 历史退市股票
- 停牌/恢复交易
- 当日是否具备可交易资格
- ST/风险警示状态变化（后续）

在完成点时股票池之前，横截面结果只能作为研究诊断，不能生成正式 T Score v0.2 权重。
